# HatchZip Homebrew tap

The official Homebrew tap for [HatchZip](https://hatchzip.dev), which extracts huge archives in place, without needing room for both the archive and its contents.

```sh
brew install xevrion/tap/hatchzip          # the command line tool, macOS and Linux
brew install --cask xevrion/tap/hatchzip   # the desktop app, macOS
```

Install one or the other: both put `hatchzip` on your PATH.

The formulas are generated from [`packaging/homebrew`](https://github.com/xevrion/hatchzip/tree/main/packaging/homebrew) in the main repository for each release. Report problems at [xevrion/hatchzip](https://github.com/xevrion/hatchzip/issues).
